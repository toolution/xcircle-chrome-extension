# Chrome Web Store listing — XCircle

## Name
XCircle — X/Twitter Interaction Circle

## Short description (132 chars max)
See who you talk with most on X. Generate, customize, download and share your interaction circle. Free via xcircle.me.

## Detailed description

XCircle turns recent public X (Twitter) interactions into a visual circle around a profile photo — no X login required.

What you can do in the extension:
• Enter any public username, or generate from the profile page you are viewing
• Choose mint / midnight / peach / paper themes
• Show 8, 24 or 50 people, with optional names and ranks
• Hide people and re-layout the circle
• Download a PNG or copy a share link hosted on xcircle.me

Website (required companion product):
https://xcircle.me

More on the site:
• How it works — https://xcircle.me/how-it-works
• Guide — https://xcircle.me/guides/how-to-make-a-twitter-circle
• X Recap — https://xcircle.me/x-recap
• Privacy — https://xcircle.me/privacy-policy

XCircle only reads public posts through xcircle.me. Likes, DMs, follows and protected accounts are not included.

## Privacy practices
Single purpose: generate interaction circle imagery from public X activity via xcircle.me APIs.
Host permissions: xcircle.me (API + avatar proxy), x.com / twitter.com (detect profile handle), pbs.twimg.com (avatars when needed).
No X password collection. No sale of personal data.
Privacy policy: https://xcircle.me/privacy-policy
